# youth_care_application


## Description

Welcome to the ** youth_care_application**, where users can easily manage their tournament participation, view events, and stay connected with instructors and admins. This app is designed to help users sign up, sign in, and engage with various features throughout the tournament process.

### Key Features

- **Sign-Up Module**:  
  Users can easily register by creating a new account. Just enter your details and get started in no time!

- **Sign-In Module**:  
  After signing up, you can log in to your account to view available events, sign up for tournaments, and access your dashboard.

- **Homepage**:  
  The homepage allows you to explore and view **available events**. You can browse through the upcoming tournaments and navigate to the **newsfeed** for real-time updates.

- **Newsfeed**:  
  Stay up-to-date with the latest updates and news about the tournament. Get notifications about changes, results, and more.

- **Contact Us Module**:  
  If you have any questions, clarifications, or concerns, you can easily **contact the instructor** directly through the app. Reach out to discuss any tournament-related issues or ask for more information.

- **Tournament Registration & Updates**:  
  Once you're signed in, you can register for tournaments and check your registration status. If any spots open up or if there are changes to registration, you will be notified immediately.

- **Easy Registration Cancellation**:  
  If you decide to cancel your registration, you can do so with ease. In case a spot opens for another student, the app will notify you if you wish to join.

### How it Works for Users

1. **Sign Up**: Create a new account with your details and get started.
2. **Sign In**: Log into your account to access your profile, view events, and more.
3. **Browse Events**: View all upcoming tournaments on the homepage.
4. **Register for a Tournament**: Sign up for the tournament of your choice.
5. **Stay Updated**: Follow the newsfeed for all important tournament updates and announcements.
6. **Contact Instructor**: If you have any questions or issues, use the contact feature to reach out to the instructor.

### Technologies Used

- **Flutter**: For building cross-platform mobile applications.
- **Firebase Authentication**: For user authentication (sign up, sign in).
- **Firebase Firestore**: For storing user data, event information, and newsfeed updates.
- **Laravel**: For building the backend API and handling business logic and server-side processes.
- **PHP**: Used in conjunction with Laravel for server-side scripting, API handling, and database interaction.
